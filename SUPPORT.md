# Support

Use GitHub Issues for reproducible defects and feature requests. Include the app
version, Linux distribution and version, desktop environment, X11 or Wayland,
package type, Codex CLI version, and sanitized logs. Do not post secrets, cookies,
private prompts, account identifiers, or proprietary source code.

Security reports belong in GitHub private security advisories as described in
[SECURITY.md](SECURITY.md). Questions about OpenAI accounts, billing, service
availability, or service policy should be directed to OpenAI support.
