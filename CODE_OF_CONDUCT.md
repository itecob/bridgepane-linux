# Code of conduct

Project spaces must remain respectful, inclusive, and focused on constructive
technical collaboration. Harassment, threats, discriminatory language, unwanted
personal attention, doxxing, and publication of another person's private data are
not accepted.

Maintainers may edit or remove contributions that violate this standard and may
temporarily or permanently restrict participation. Enforcement decisions should
consider context, impact, good-faith correction, and community safety.

Report conduct concerns privately through the repository owner's GitHub contact
or private security reporting when public disclosure would expose someone to
harm. Reports will be handled as confidentially as reasonably possible.

This policy applies in repository discussions, reviews, issue trackers, and other
spaces where a person represents this project.
