# BridgePane

**An unofficial ChatGPT + Codex desktop client for Linux.**

> **Unofficial alpha software.** This community project is not affiliated with,
> endorsed by, or sponsored by OpenAI. Do not treat prerelease builds as a stable
> production client.

A Linux desktop application with two intentionally separate modes:

- **ChatGPT** loads the official `https://chatgpt.com` web application in an
  isolated Electron session.
- **Codex** provides a native project and conversation interface backed by the
  official `codex app-server` stdio protocol.

The modes keep separate histories, cookies, and authentication state. The Codex
client accepts ChatGPT OAuth/device-code authentication and deliberately rejects
API-key and externally injected token login.

## Release status

The repository is suitable for source review and alpha testing. A release may be
called stable only after the clean-VM matrix in [docs/RELEASING.md](docs/RELEASING.md)
passes. Native `.deb` and `.rpm` packages are the supported release direction.
AppImage remains experimental until its Chromium sandbox works reliably on Linux
systems that restrict unprivileged user namespaces.

## Security and privacy

- The ChatGPT surface has no preload, Node.js integration, DOM automation, cookie
  access, download permission, or native IPC access.
- Remote navigation is restricted to OpenAI and exact supported identity-provider
  hosts. Other HTTPS links open in the system browser.
- The native renderer is sandboxed and every privileged IPC operation verifies
  the exact renderer and main frame.
- `OPENAI_API_KEY` and `CODEX_ACCESS_TOKEN` are removed from Codex child processes.
- App-server request IDs are remapped, bounded, and denied when the UI disconnects.
- Plugin commands use argument arrays without a shell and validate identifiers.
- Production `--no-sandbox` operation is prohibited.

Read [SECURITY.md](SECURITY.md), [PRIVACY.md](PRIVACY.md), and the
[threat model](docs/THREAT_MODEL.md) before distributing or deploying the app.

## Requirements

- Linux
- Node.js 22 or newer for source builds
- A current official [Codex CLI](https://developers.openai.com/codex/cli/)
  available as `codex`
- A working [Bubblewrap sandbox](docs/LINUX_SANDBOX.md); Ubuntu 24.04 may require the distribution AppArmor profile
- A ChatGPT plan with Codex access

Protocol bindings and live smoke tests are validated against Codex CLI 0.145.0. Older CLI versions are unsupported for this alpha; newer versions must pass `npm run smoke` and schema-diff review before a stable compatibility claim.

Run `codex login` first if desired, or use the native Codex sign-in screen. Set
`CODEX_BINARY` to an absolute executable path when the CLI is outside normal
desktop-session lookup paths.

## Development and validation

```bash
npm ci
npm run verify
npm run smoke
```

`npm run verify` performs strict TypeScript checks, unit/security tests, repository
release-policy validation, and production builds. `npm run smoke` starts the real
installed Codex app-server, initializes it, and reads account state without
starting a turn.

Runtime dependency audit:

```bash
npm audit --omit=dev --audit-level=high
```

The complete development/build dependency audit must also be reviewed before a
release because release-tool vulnerabilities can affect artifact integrity even
when they are absent from the installed runtime.

## Packaging

```bash
npm run package:deb
npm run package:rpm
```

Artifacts are written to `release/`. Do not distribute locally built artifacts as
official releases. Tagged GitHub builds generate checksums, CycloneDX SBOMs, and
GitHub build-provenance attestations.

## Plugins

The plugin manager lists plugins exposed by configured Codex marketplaces and
invokes the stable `codex plugin` CLI for installation and removal. Review plugin
source and requested capabilities before installation. Start a new Codex thread
after changes. No marketplace is added automatically.

## Architecture

- `desktop/main/` — Electron lifecycle, security boundaries, ChatGPT view, Codex
  transport, and plugin operations
- `desktop/preload/` — narrow capability bridge for the local renderer
- `desktop/renderer/` — React interface and state normalization
- `src/codex-app-server.ts` — bounded app-server stdio transport
- `src/router.ts` — single-client RPC mapping and fail-closed server requests
- `src/policy.ts` — OAuth-only request policy
- `src/generated/codex/` — bindings generated by the official Codex CLI
- `test/` and `desktop/test/` — protocol, policy, routing, UI-model, plugin, and
  security tests

OpenClaw is not bundled or required.
